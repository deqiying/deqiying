## 关于我

我喜欢把模糊问题拆成可验证、可维护、可自动化的系统。比起堆功能，我更在意边界是否清晰、证据是否可靠、工具是否真的能让下一次工作更省力。

- 关注 `AI Agent`、developer tools、backend services、infra automation 与 CLI-first workflows
- 偏好设计先行、证据驱动、渐进交付，以及能长期维护的小接口
- 常用 `Go`、`Java`、`C#`、`Kotlin`、`C`、`Rust`、`Docker` 和 GitHub workflows
- Motto: **Code is cheap. Show me the design.**

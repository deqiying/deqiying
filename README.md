## 关于我

我喜欢把模糊问题拆成可验证、可维护、可自动化的系统。比起堆功能，我更在意边界是否清晰、证据是否可靠、工具是否真的能让下一次工作更省力。

- 🐋 关注 `AI Agent`、developer tools、backend services、infra automation 与 CLI-first workflows
- 🫧 偏好设计先行、证据驱动、渐进交付，以及能长期维护的小接口
- 🛠️ 常用 `Go`、`Java`、`C#`、`Kotlin`、`C`、`Rust`、`Docker` 和 GitHub workflows

## 正在构建

| 方向 | 在做什么 |
| --- | --- |
| 🧭 **Agent Workflows** | 可复用的 agent skill、plugin、tooling 与工作流，让自动化结果更稳定、更可审计 |
| 🔧 **Developer Tools** | 面向终端、脚本和 AI agent 的 CLI-first 工具，强调证据、检索、调试与可组合性 |
| ⚓ **Backend Systems** | 简洁可靠的服务端设计：清晰配置、可观测状态、明确错误边界和可验证行为 |
| 🔁 **Infra Automation** | 把环境、部署、配置和排障流程沉淀成可重复执行的工程资产 |
